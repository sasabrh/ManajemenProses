play_arrow Pokok Bahasan 1: Definisi Proses

Apa Itu Proses?

Proses adalah suatu kegiatan atau program yang sedang dieksekusi. Sebuah proses bisa dianggap sebagai unit aktivitas yang ditandai dengan urutan instruksi, status saat ini, dan sejumlah sumber daya sistem yang terkait.
description Program (Entitas Pasif)

Kumpulan instruksi biner yang tersimpan diam di hard disk / SSD. Seperti buku resep masakan di rak buku, belum ada koki yang memasak.

bolt Proses (Entitas Aktif)

Program yang dimuat ke RAM dan sedang dieksekusi CPU. Memiliki memori, pencatat register, status kerja, dan membutuhkan sumber daya.

folder_shared Pokok Bahasan 2: Process Control Block (PCB)
KTP Digital Proses

Process Control Block (PCB)

PCB adalah blok yang menggambarkan informasi penting suatu proses. Fungsinya adalah menyimpan informasi yang cukup untuk menghentikan sementara proses yang sedang berjalan dan melanjutkannya kembali tanpa kehilangan data. PCB adalah alat utama yang memungkinkan sistem operasi mendukung multi pemrosesan.

1 fingerprint

Identifier (Pengenal)

Nomor unik (PID) untuk membedakan proses satu dengan proses yang lainnya di sistem.

2 sync

State (Status)

Keadaan proses saat ini (misalnya: berjalan, menunggu I/O, atau diblokir).

3 priority_high

Priority (Prioritas)

Tingkat kepentingan proses dibanding yang lain, proses terpenting akan terlebih dahulu dieksekusi CPU.

4 pin_invoke

Program Counter

Penunjuk yang menyimpan alamat instruksi berikutnya yang akan dieksekusi saat proses dilanjutkan kembali.

5 memory

Memory Pointers

Lokasi kode program dan data dalam memori utama (RAM) agar tidak tumpang tindih.

6 developer_board

Context Data

Data yang disimpan di register CPU saat proses sedang berjalan (snapshot nilai kalkulasi).

7 keyboard

I/O Status Information

Status permintaan input/output dan perangkat yang sedang digunakan (misal: keyboard, hard disk).

8 query_stats

Accounting Information

Catatan penggunaan sumber daya sistem seperti waktu penggunaan CPU, batas waktu, dan user account.

Status Proses & Siklus Hidup

Status proses adalah kondisi yang menggambarkan kegiatan suatu proses pada waktu tertentu. Status ini berubah-ubah sepanjang "hidup" proses mulai dari dibuat hingga selesai.

speed Pokok Bahasan 4: Eksekusi Proses & Dispatcher
Dispatcher & Context Switch

Eksekusi Proses & Mekanisme Dispatcher

Eksekusi proses adalah kegiatan CPU dalam menjalankan instruksi-instruksi suatu proses secara berurutan, sesuai alamat yang tercatat pada Program Counter di PCB-nya. Karena CPU hanya dapat mengeksekusi satu instruksi dalam satu waktu, sistem operasi menjalankan banyak proses secara bergiliran sehingga tampak seperti berjalan bersamaan. Kemampuan ini disebut multiprogramming.

swap_horiz Apa itu Context Switch?

Perpindahan CPU dari satu proses ke proses lain disebut Context Switch. Sistem operasi menggunakan Dispatcher untuk menghentikan sementara proses lama, menyimpan posisinya (Program Counter & Register) ke dalam PCB, lalu memuat informasi PCB proses baru. Inilah jawaban mengapa smartphone terasa multitasking padahal single core!

Rangkuman Materi Pembelajaran

Pada CPU satu inti, hanya 1 proses yang dieksekusi di setiap saat. Kesan "bersamaan" muncul karena dispatcher berpindah antarproses dengan sangat cepat. Proses Running bisa berpindah ke Waiting (saat butuh I/O), lalu kembali ke Ready. Siklus ini bisa berulang beberapa kali. OS melewati tahap Terminated untuk secara resmi melepas PCB dan sumber daya yang dipakai proses tersebut.
